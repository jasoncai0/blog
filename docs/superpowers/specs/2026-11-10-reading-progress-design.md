# 阅读进度（百分比）设计

2026-11-10 · 已选方案 C：文章页进度条 + 首页标注 + 断点续读

## 意图

每篇文章记住读到百分之多少：下次回首页能看到「这篇读到 62%」，点进去能接着上次的位置往下读，阅读过程中右下角有常驻百分比。
数据只存浏览器本地，不上报、不同步、不跨设备。

## 目标 / 非目标

**目标**
- 文章页顶部一条 2px 进度条，随滚动实时填充。
- 右下角常驻小胶囊显示实时百分比（`62%`，读到 95% 以上显示「读完」）。
- 存每篇的**最大**进度；再次打开同一篇时自动滚回上次位置，并给出一次轻提示「从 62% 继续」。
- 首页每篇文章显示本地记录的进度（`62%` / `已读完`），没有记录就不显示标记。
- 无 JS 时一切照旧（进度 DOM 全部由 JS 注入）。

**非目标**
- 不做服务器同步、账号、跨设备。
- 不统计停留时间、不埋点上报。
- 不做「滚动到顶自动标记未读」之类的额外语义。

## 约束

- 站点目前没有任何 JS。只加一个文件，通过 Hugo Pipes 打包 + fingerprint，自托管，不引第三方。
- 纸感主题：进度条与胶囊用已有的 `--accent: #bf4520`，数字用 `--muted` 和等宽字体。
- 构建与发布流程不变。
- 页面全局有 `html { scroll-behavior: smooth }`；续读必须瞬时定位，不能被它拖成动画。

## 实现要点

**文件**
- `assets/js/reading-progress.js`（新增，约 130 行）
- `layouts/_default/single.html`：正文容器加 `data-progress-post="<slug>"`，文章页引入脚本。
- `layouts/index.html`：每个 `<li>` 加 `data-progress-post="<slug>"`，条目内预留空的 `<span class="read-mark">`。
- `assets/css/site.css`：`.rp-bar` / `.rp-num` / `.rp-chip` / `.rp-hint` / `.read-mark`。

**百分比怎么算**
- 0 点 = 正文顶部对齐视口顶部；100 点 = 正文底部进入视口。
- `(viewportBottom - contentTop) / contentHeight`，截到 0–100 取整。
- 整页无法滚动（短文一屏放得下）时记 100。
- 滚动用 `requestAnimationFrame` 节流；写 localStorage 再节流到 1s。

**存储**
- 单一键 `jasoncai:read:v1`：`{ "<slug>": { "p": 62, "t": 1762745187000, "d": false } }`。
- `p` 最大进度，`t` 最后更新，`d` 是否读完（`p >= 95` 置真，只增不减）。
- 修剪：最多 300 条，按 `t` 丢最旧；单条 180 天未更新也丢。
- 读写包 try/catch（隐私模式、配额满不得让页面报错）。

**断点续读**
- 打开文章页时，若本地 `5 <= p < 95`：按公式反算 `scrollY` 瞬时定位（临时把 `scroll-behavior` 设成 `auto`），然后显示 2.5 秒的提示「从 62% 继续」，淡出后移除。**不用 `history.scrollRestoration = "manual"`**：实测它会让后退回到文章页时落在 0（953 → 0），而浏览器的默认恢复本来就是对的；改用「`scrollY` 已非 0 就不续读」来避让。
- 满足以下任一条件不续读：`p < 5`（本来就在顶部附近）、`p >= 95`（已读完）、导航类型是 `back_forward`（浏览器自己会恢复，避免双重定位）、页面加载时 `scrollY` 已非 0（用户或锚点先动了）。
- 锚点链接（URL 带 `#`）优先于续读，不抢。

**展示**
- 顶部进度条：`position: fixed` 的 2px 线，`--accent` 填充；对辅助技术暴露 `role="progressbar"` + `aria-valuenow`。
- 右下角胶囊：固定定位，字号 11–12px、等宽数字；滚动超过 2% 才出现，避免一进页面就挡住正文；纸感主题里用细边框和半透明纸色底。
- 首页：只读存储，`62` → `62%`，`d` 为真 →「已读完」；读不到或没记录就不渲染。标记放在 tag chips 之后，不改动现有布局与排序。

## 取舍（我的判断）

- 进度条与胶囊显示**当前滚动位置**，首页显示**历史最大值**：往回滚时条子会退、胶囊会退，首页的 62% 不退，两处语义各自清楚。
- 「读完」阈值 95%，避免最后一屏差几个像素永远读不完。
- 续读提示只在真的发生了跳转时出现，不做常驻的「上次读到 62%」横幅。
