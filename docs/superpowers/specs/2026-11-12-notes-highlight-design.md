# 划词高亮与批注（本地笔记）

2026-11-12 · 已选方案 A（文字锚点）

## 意图

在文章里选中一段话，把它标成高亮，并可以挂一句批注。全部存在浏览器本地，不上传、不需要账号。有笔记的文章在首页能被一眼看见，方便回头找。

笔记要记下**是谁写的**；批注是一个可以往后追加的线程，将来 AI 回答某个提问时，作为同一线程里的另一条追加，而不是覆盖原批注。

## 目标

- 选中正文任意文字 → 浮出小工具条「高亮」「记笔记」。
- 高亮持久：刷新、换标签页、下次打开仍在原位。
- 点高亮 → 气泡里看批注、改批注、删高亮。
- 文章页列出本文笔记（条数、片段、作者、时间），点击跳回高亮。
- 首页在 tag 行后显示「有笔记 ·N」，无笔记不占位。
- 导出 JSON（防换浏览器丢数据）。
- 无 JS、localStorage 被禁用时不报错、不破坏阅读。

## 非目标

- 不做账号、云同步、跨设备合并。
- 本期不做 AI 回答的生成，只把数据结构留成线程。
- 不做批注的富文本（纯文本即可）。

## 约束

- 站点是纯静态 Hugo，没有后端；一切存 `localStorage`。
- 正文 HTML 由 Hugo 每次构建重新生成，DOM 结构可能变（加图、改标题层级），所以锚点不能依赖 DOM 节点引用或固定字符下标。
- 移动端没有 hover，点按也要能出工具条。
- 与已有功能共存：阅读进度（`jasoncai:read:v1`）、目录折叠、图放大。

## 方案

- **A. 文字锚点（选用）**：存选中文字 `q` + 前后各 32 字 + 段落序号 `block`，恢复时用 TreeWalker 在段落文本里找回来。文章改写后只要那句话还在就能定位。
- **B. 字符偏移**：存段落下标 + 起止字符偏移。实现最简单，但正文改一个字，后面所有高亮错位。否。
- **C. CSS Custom Highlight API**：锚点同 A，只交给浏览器绘制。性能好，但 Safari 17.2 以下不支持，本站读者可能用旧 Safari，会出现"高亮丢了"。否。

选 A 的代价是写一个跨节点定位函数，以及处理"文字被改过找不到"的情况；换来的是改文章不炸。

## 设计

### 数据

`localStorage["jasoncai:notes:v1"]`：

```json
{
  "posts/ot-crdt-lww": [
    {
      "id": "n17ab3",
      "q": "LWW 不是与 OT、CRDT 并列的第三种算法",
      "pre": "它当然是合法的 CRDT——max 满足交换、结合、幂等。所以准确地说，",
      "post": "，它是 CRDT 里的一个寄存器类型（LWW-Register）",
      "block": 12,
      "t": 1762900000000,
      "thread": [
        { "author": "我", "text": "这句话和上一节矛盾，回头核对", "t": 1762900000000 }
      ]
    }
  ]
}
```

- `block`：`.post-body` 直接子元素的下标，只作首选提示，找不到时退回全文搜索。
- `thread`：`[0]` 是人写的批注；将来 AI 回答作为 `{author: "AI", text, t}` 追加，不覆盖原文。
- 只写不查 payload，全部是本地数据，不涉及服务端。

### 锚定

- 取锚：`range.getBoundingClientRect` 定位块；`q = range.toString()`；`pre/post` 用块内文本切片，块边界处截断。
- 恢复：先在第 `block` 块里找 `q`，校验 `pre/post` 是否对得上；对不上再全文扫一遍取唯一匹配；仍失败则记一条 `miss`，不画高亮，控制台不报错。
- 渲染：对匹配区间做 TreeWalker 拆分文本节点，逐节点包 `<mark class="note-hl" data-note="<id>">`，跨节点时多个 mark 共享同一 id（点击任一段都打开同一条）。
- 只处理 `.post-body` 内、且不落在 `pre/code/figcaption` 里的选区；跨块选择拒绝并提示"一次选一段"。

### 交互

- 选中后 `mouseup` / `selectionchange` 防抖 120ms 出工具条，位置在选区上方 8px，超出视口则放下方。
- 「高亮」：直接落库，`thread` 为空。
- 「记笔记」：高亮 + 立即弹输入框；保存写入 `thread[0]`，作者 "我"。
- 点已有高亮：气泡显示片段、作者、时间、批注；可编辑（改写 `thread[0].text`）、可删除（整条删除）。
- 键盘：高亮可 Tab 聚焦，Enter 打开气泡；气泡 Esc 关闭。
- 工具条固定在 `document.body`，`position: absolute`，随滚动关闭。

### 页面

- 文章页左栏目录底部加 `.note-list`（无目录的文章放正文末尾）：「本文笔记 ·N」，每条一行，点击滚到对应高亮并闪 1.2s；底部「导出 JSON」「清空本文笔记」。
- 首页 `li` 的 `.post-foot` 里加 `<span class="note-mark"></span>`，由 JS 填「有笔记 ·N」，无则移除。
- 无 JS：以上都不出现。

### 样式

沿用纸感 token：高亮 `background: rgba(191,69,32,.16)`、`box-shadow: inset 0 -1px 0 rgba(191,69,32,.35)`；工具条与气泡用 `--paper` 底、`--rule` 边、11–12px 字号，跟目录/胶囊一致。

## 测试

- 选词出工具条、按钮可用。
- 高亮后 reload 仍在；换页面再回来仍在。
- 加批注后气泡显示作者"我"与文字；改、删生效。
- 跨节点选区（一句话里有 `<code>` 或 `<strong>`）能正确分段包裹。
- 文章改字导致找不到时：不崩、不误标。
- 首页「有笔记 ·N」出现，删除最后一条后消失。
- localStorage 抛异常时不产生 pageerror。
- 无 JS 页面无工具条、无 mark。
