# 侧栏目录、写作日历与上次读到位置 — 设计

日期：2026-11-12
状态：待实现（方案 A 已由用户选定）

## 1. 目标

三件事共用页面左侧的一条栏：

1. **首页左栏**：写作日历热图（上）+ 标签云（下）。标签云从首页顶部移入左栏。
2. **文章页左栏**：目录。可折叠（展开 220px / 收起 44px），滚动时高亮当前章节，点击跳转。
3. **文章页正文**：上次读到位置的可见标记——一条淡色横线 + 「上次读到这」标签。

已有的阅读进度（顶部进度条、右下角胶囊、自动续读）保持不变。

## 2. 数据现实（影响设计）

53 篇文章只落在 5 天：11-02(2)、11-09(15)、11-10(7)、11-11(28)、11-12(1)。
一年 53 周的格子会有 366 个空格、5 个有色格。这不是数据错误，是真实节奏。

决定：**照实显示**，不做平滑、不做假数据。默认只显示最近 12 周（每格一天），
让「最近写了什么」成为第一眼信息；「全年」作为可切换视图。空格用极浅的纸色，
有色格用 accent 的四级透明度——读起来像一张标了几个日子的日历，而不是一张坏掉的贡献图。

## 3. 布局

- `.page` 最大宽度 1080 → **1240px**。
- 首页与文章页共用两栏骨架：`grid-template-columns: 240px minmax(0, 1fr); gap: 56px`。
- 左栏 `position: sticky; top: 96px; align-self: start; max-height: calc(100vh - 160px); overflow-y: auto`。
- 文章页正文宽度从约 984px 降到约 944px（1240 - 48×2 - 240 - 56），几乎无感。
- **<900px**：左栏不再粘住，按文档流排到正文之前——首页是「日历 + 标签」在上、列表在下；
  文章页是「目录」折叠条在上，点开原地展开（不是抽屉，避免遮住正文）。

## 4. 写作日历（首页左栏）

### 渲染

Hugo 模板直接生成整年的格子，不请求 JSON：

- 范围：当年 1 月 1 日所在周（周一起）到 12 月 31 日所在周，或最近 53 周（取包含今天的周为最后一列）。
- 每格 `<a class="heat-cell" data-date="2026-11-11" data-count="28" href="/#d-2026-11-11">`；
  无文章的日期渲染为 `<span class="heat-cell is-empty" data-date="…">`，不可聚焦、`aria-hidden` 由标题列表承担。
- 颜色四级：1 篇 / 2 篇 / 3–4 篇 / ≥5 篇。
- 每列首格若跨月，标注月份缩写。
- 可访问性：`<nav aria-label="写作日历">`，每格 `aria-label="2026-11-11，28 篇"`，外层 `<p class="sr-only">` 说明色阶含义。

### 交互（需要 JS，无 JS 时静态可用）

- 默认窗口：最近 **12 周**；按钮「近 12 周 / 全年」切换。
- `‹` `›` 按 12 周平移（全年视图下按 3 个月平移）。
- `<input type="date">`：选中日期后，窗口平移到包含该日的那 12 周，并把那一列加 `.is-target` 高亮 2 秒。
- 点击有文章的格子：跳到 `/#d-YYYY-MM-DD`。列表页 JS 找到所有 `li[data-date="…"]`
  （渲染时新增该属性），滚到第一条，给它们加 `.is-flash`（1.6 秒后移除）。
  同一天多篇时全部高亮，用户能看到那天一共写了几篇。
- 点击空格子：无动作。

## 5. 目录（文章页左栏）

- `single.html` 里现有的 `nav.toc` 从正文流移入左栏，保留 `{{ .TableOfContents }}` 的输出。
- 折叠：按钮切换 `.is-collapsed`（栏宽 220px → 44px，只留一条竖向的「目录」二字 + 章节刻度点）。
  状态存 `localStorage` 的 `jasoncai:toc:collapsed`，默认展开。
- 滚动高亮：`IntersectionObserver` 观察 `.post-body` 内的 `h2, h3`，
  取当前视口顶部附近最后一个进入的标题，对应 `a[href="#id"]` 加 `.is-active`（左侧 2px accent 竖线 + 强调色）；
  高亮项若滚出左栏可视区，自动 `scrollIntoView({block:'nearest'})`。
- 点击链接：平滑滚动（沿用 `html { scroll-behavior: smooth }`），**不自动折叠**——
  连续跳两节是常见操作，折起来会让人再点一次。窄屏折叠条内点击时，跳转后收起。
- 无 JS：目录照常显示、链接照常跳转，只是没有高亮和折叠按钮。

## 6. 上次读到位置的标记

- 数据来源：已有的 localStorage 条目 `{p,t,d}`（同一篇的进度）。
- 打开文章后，若 `p ≥ 5` 且 `p < 95`，在正文里按 `scrollForProgress(p)` 算出纵坐标，
  插入 `<div class="rp-marker"><span>上次读到这 · 62%</span></div>`，`aria-hidden="true"`
  （它是视觉书签，塞进读屏顺序只会打断阅读）。
- 样式：1px 虚线 `var(--rule)`，左侧标签小号 mono、`var(--soft)`，距左边缘 -8px 起。
- 消失条件：用户往下滚、标记顶端离开视口顶部（`rect.bottom < 0`）→ 加 `.is-passed`（透明度 0，0.4s），
  之后从 DOM 移除。往回翻仍能看到它，直到读过去。
- 与自动续读共存：若这次打开触发了续读（`shouldResume` 为真且真的滚了过去），
  **不显示标记**——「从 62% 继续」的提示已经说清了位置，两者叠加会重复。
- 无 JS：不显示（它本来就是增强）。

## 7. 无 JS 与降级总表

| 内容 | 无 JS |
| --- | --- |
| 标签云 | 正常（静态链接） |
| 日历格子与颜色 | 正常；窗口固定为最近 12 周，切换/平移/日期跳转不可用 |
| 目录与锚点跳转 | 正常 |
| 目录折叠、滚动高亮 | 不可用（按钮 `hidden` 由 JS 摘掉） |
| 上次读到位置 | 不显示 |
| 阅读进度条/胶囊 | 已有行为不变（不显示） |

## 8. 测试

- 纯逻辑 `assets/js/calendar-core.mjs`（`node --test`）：周对齐、窗口平移、日期 → 列索引、色阶分级、跨年边界。
- 浏览器 `scripts/tests/test_sidebar.py`（Playwright，本地 `python3 -m http.server` 随机端口）：
  1. 首页左栏存在日历与标签，顶部没有 tag-cloud；
  2. 点击 11-11 的格子 → 对应 `li` 被 flash、页面滚到该条附近；
  3. 日期输入 2026-11-09 → 该周进入窗口并 `is-target`；
  4. 文章页目录在左栏、滚动到第 3 节时该链接 `.is-active`；
  5. 点折叠 → 栏宽 ≤ 60px，刷新后仍收起；
  6. 打开有 62% 记录的文章 → `.rp-marker` 存在；滚过之后消失；
  7. 无 JS：目录、日历、标签、正文都在。
